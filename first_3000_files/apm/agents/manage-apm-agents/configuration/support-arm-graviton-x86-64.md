The following New Relic agents support AWS Graviton processors using ARM64, as well as x86_64.

# Table

| New Relic product | ARM64/Graviton support | x86_64 support | ARM64/Graviton version |
| - | - | - | - |
| Python agent | Yes | Yes | Version [6.8.0.163](/docs/release-notes/agent-release-notes/python-release-notes/python-agent-60800163/) and on |
| Ruby agent | Yes | Yes | Version [8.0.0](/docs/release-notes/agent-release-notes/ruby-release-notes/ruby-agent-800/) and later |
| Node.js agent | Yes | Yes | Version [8.5.0](/docs/agents/nodejs-agent/getting-started/compatibility-requirements-nodejs-agent/) and later |
| .NET agent | Yes | Yes | Version [9.1.0](/docs/apm/agents/net-agent/getting-started/net-agent-compatibility-requirements/) and later |
| Go agent | Yes | Yes | Version [3.15.1](/docs/release-notes/agent-release-notes/go-release-notes/go-agent-3-15-1/) and later |
| PHP agent | Yes | Yes | Version [9.18.1](/docs/apm/agents/php-agent/installation/php-agent-installation-arm64/) and later |
| Java agent | Yes | Yes | Version [7.4.0](/docs/release-notes/agent-release-notes/java-release-notes/java-agent-740/) and later |
| Infrastructure agent | Yes | Yes | Version [1.20.6](/docs/infrastructure/install-infrastructure-agent/get-started/requirements-infrastructure-agent/) and later |
| On-host integrations | Yes | Yes | Support for ARM64/Graviton, except [Oracle Database OHI](/docs/integrations/host-integrations/host-integrations-list/oracle-database-monitoring-integration/) |
